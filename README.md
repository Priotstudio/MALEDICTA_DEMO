📜 MALEDICTA_DEMO

A Gothic-style 3D adventure built in Godot


🎮 About

This is an indie 3D game inspired by British Gothic architecture, featuring world streaming, dynamic inventory, and performance-friendly rendering. Developed using Godot Engine, it focuses on efficient open-world exploration with lightweight lighting and chunk-based level streaming.


✨ Features

Open-world exploration with seamless chunk loading
PSP-style graphics with optimized 3D models
Dynamic inventory system like Monster Hunter
Custom fake lighting and shadows for performance
Minimap system with circular UI support


🎨 Assets & Tools

Developed with Godot Engine
Gothic-style models created with simple modeling tools
Textures and props inspired by classic adventure games
